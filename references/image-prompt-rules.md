# 分页图片提示规则

## 基础规格

- 竖版 3:4，适合手机阅读，高清。
- 每页保持同一套色板、字体气质、图形语言、边距和信息层级。
- 封面先生成；模型支持参考图时，将封面作为后续页的样式参考。
- 使用 Gemini API 时必须通过 `scripts/generate.py` 出图；脚本会加载 `assets/image_prompt.txt` 的完整生成模板，并把已生成封面作为 `@封面参考图` 发送给后续每一页。
- 不生成手机外框、平台 Logo、账号 ID、水印或无关签名。

## 完整提示词组成

每个 `image_prompt` 必须独立描述：

1. 页面用途和类型。
2. 画面主题、主体、动作和场景。
3. 构图、镜头、留白和视觉动线。
4. 色板、光线、材质和插画/摄影风格。
5. 文字层级和精确的 `text_overlay`。
6. 与整套作品统一的视觉规则。
7. 禁止元素与事实边界。

不要只写“同上”“参考上一页”或“做得高级”。

`image_prompt` 只写本页额外视觉指令。不要在其中重复完整系统规则；生成脚本会自动注入页面内容、完整大纲、用户主题、参考图映射与统一设计规范。

## 文字可靠性

只有在模型擅长排版目标语言时，才要求直接渲染较多文字。否则优先生成带明确留白的背景/插画，并把文字、字号层级、位置和颜色写入 `text_overlay`，交给后续排版工具处理。

## 参考图

- 普通参考图只用于风格、构图、氛围、色调或版式节奏，不复制水印、Logo、人物身份或独特作品。
- 明确标注每张参考图的用途，避免把所有图无差别传入每一页。

## 产品图

- 产品图代表必须保真的真实物品，不是风格灵感。
- 明确产品在桌面、台面、前景、背景或左中右区域的位置。
- 保留包装、颜色、形状、商标和核心识别细节，不替换为相似产品。
- 允许调整光影、透视和相对比例以融入场景，但避免遮挡或复杂手持。
- 图片模型不支持参考图时，不声称完成了产品保真植入。
