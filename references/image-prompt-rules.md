# 分页图片提示规则

## 基础规格

- 竖版 3:4，适合手机阅读，高清。
- 每页保持同一套色板、字体气质、图形语言、边距和信息层级。
- 封面先生成；模型支持参考图时，将封面作为后续页的样式参考。
- 使用 Gemini API 时必须以确认后的 `outline.json` 运行 `scripts/generate.py --outline <outline.json>`；脚本直接使用原始 `pages[].content`，并把已生成封面作为 `@封面参考图` 发送给后续每一页。
- 不生成手机外框、平台 Logo、账号 ID、水印或无关签名。

## 原始大纲是唯一图片输入

- 不要让 Agent 为图片生成重新撰写 `image_prompt` 或结构化页面文案。
- 直接使用大纲模型返回的原始 `pages[].content`、完整 `outline` 和原始 `topic`。
- 用户修改页面时只修改对应的原始分页内容，其他页面保持逐字不变。
- 生成脚本负责注入完整图片模板、参考图映射和产品图规则。

## 文字可靠性

只有在模型擅长排版目标语言时，才要求直接渲染较多文字。否则优先生成带明确留白的背景/插画，并把文字、字号层级、位置和颜色写入 `text_overlay`，交给后续排版工具处理。

## 参考图

- 普通参考图只用于风格、构图、氛围、色调或版式节奏，不复制水印、Logo、人物身份或独特作品。
- 明确标注每张参考图的用途，避免把所有图无差别传入每一页。

## 产品图

- 产品图代表必须保真的真实物品，不是风格灵感。
- 明确产品在桌面、台面、前景、背景或左中右区域的位置。
- 保留包装、颜色、形状、商标和核心识别细节，不替换为相似产品。
- 允许调整光影、透视和相对比例以融入场景，但避免遮挡或复杂手持。
- 图片模型不支持参考图时，不声称完成了产品保真植入。
