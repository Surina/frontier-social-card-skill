# 分页策划规则

## 目标

把主题转成适合手机连续阅读的完整叙事。每一页只承担一个主要信息任务，并能独立生成画面。

初次大纲必须由 `scripts/generate_outline.py` 调用配置的文本模型生成。脚本使用 `assets/outline_prompt.txt` 的完整原始模板，并按 `<page>` 解析。不要由 Agent 根据本文件自行重写一个替代大纲。

确认时展示模型返回的详细分页原文，不压缩成表格或一句话摘要。

## 默认结构

1. 封面：一个明确利益点或好奇点，包含短标题和可选副标题。
2. 背景/痛点：让目标读者迅速确认“这和我有关”。
3. 核心内容：按步骤、清单、误区、对比或场景拆分，每页一个观点。
4. 总结/行动：回收核心信息，给出自然互动或下一步。

默认 6–8 页；用户指定时允许 2–18 页。不要为了凑页数重复观点。

## 每页字段

- `index`: 从 1 连续编号。
- `type`: `cover`、`content` 或 `summary`。
- `headline`: 适合直接放在画面上的短标题。
- `body`: 1–5 条短信息，避免大段文字。
- `visual`: 主体、场景、构图、色彩、材质与装饰元素。
- `text_overlay`: 必须准确显示的文字；保持短小。
- `reference_images`: 使用的普通参考图路径。
- `product_images`: 必须植入的产品图路径。
- `image_prompt`: 无需依赖上下文即可执行的完整图片提示词。

## 质量检查

- 第一页必须是 `cover`。
- 页面顺序必须形成清楚的信息推进。
- 标题和内容不得承诺正文没有提供的价值。
- 事实性内容不确定时标注待核实或改成经验型表达。
- 产品出现在哪一页必须明确，不要把产品图当作风格图。
- 避免抄袭参考材料的独特措辞、版式、人物或品牌识别元素。
